# 运行命令（Toolbox 工具 11）

> 按热键调出一个输入框，把命令交给 **cmd** 或 **PowerShell** 执行，输出当场显示。

---

## ⚠️ 先读这一段：这是工具箱里唯一能"执行任意命令"的功能

别的工具（截图 / 哈希 / 改名 / 二维码）都是**有限的、可预期的**动作，你能预判它会干什么。
**这个不一样**：输入什么就执行什么，能力上不封顶 —— 可以删文件、改注册表、装东西、下载东西。

所以本工具**刻意**做成这样，这几条不是可选项：

| 设计 | 为什么 |
|---|---|
| **绝不自动执行** | 必须你亲手点「执行」或按 **Ctrl+Enter**。**单独回车是换行**，不会执行 |
| **执行前把命令行原样显示** | 黄框里是最终拼给 shell 的完整参数（含 `/c`、`-NoProfile` 等），你能核对 |
| **输出完整回显** | stdout + stderr + 退出码全给，不做任何"看起来好像成功了"的美化 |
| **不做"危险命令拦截"** | 见下 |

### 为什么不做危险命令黑名单

黑名单**永远是漏的**：`rm` 能写成 `r''m`，`del` 能写成 `d^el`，
混淆方式无穷无尽。更要命的是，给了你"它帮我挡住了"的错觉**反而更危险** ——
你会因此放松警惕。

**这个功能本来就等于你打开了那个 shell**，能力边界就是你的账户权限。
所以正确的做法是把这件事**如实说清楚**（界面上也标了那句警告），让你自己决定跑什么。

> 想安全地试：先跑 `echo hello` 这种只读命令。确认链路通了再跑别的。

## 依赖

| 项 | 说明 |
|---|---|
| 第三方库 | **无** |
| 外部程序 | **系统自带**：`cmd.exe` 一定有；PowerShell 用 `pwsh`（7+，有则优先）或系统自带的 `powershell.exe`（5.1） |
| 复用 | 工具注册/热键/悬浮窗（`IToolboxTool`）、写剪贴板（`ClipboardWriter`）、日志（`Log`）、托盘气泡 |

## 用法

| 操作 | 说明 |
|---|---|
| **热键** | `Win+Alt+X`（被占用时降级到 `Win+Shift+B` / `Ctrl+Alt+X`） |
| 选 shell | 顶部下拉框：**命令提示符（cmd）** / **PowerShell**；右边会显示解析到的 exe 路径与版本 |
| 输入命令 | 支持多行（**回车 = 换行**） |
| 执行 | 点「执行」或按 **Ctrl+Enter** |
| 取消 | 执行中可点「取消」（会**杀掉整个进程树**） |
| 复制输出 | 把输出区内容送进剪贴板（带自污染标记，不进剪贴板历史） |

**超时**：单条命令默认 60 秒。超时会**真的杀掉进程**，不会留一个挂着的 shell。

## 实现要点

- **参数用 `ArgumentList` 传，不手拼字符串** —— 命令里有引号、空格、中文时，
  手拼命令行几乎必错（本项目在格式转换那边已经踩过同一个坑）。
- **cmd 带 `/d`**（跳过 AutoRun）与 **`/c`**（执行完退出）；
  AutoRun 会让同一句话在不同机器上行为不同。
- **PowerShell 带 `-NoProfile` 与 `-NonInteractive`**：
  前者保证行为可预期（不被用户的 profile 影响），
  后者让"需要输入的命令"直接失败，而不是**默默挂住**等输入。
- **输出编码按实际代码页解码**（见下）。

## 踩过的坑：中文输出乱码

第一版的做法是"给命令前面加 `chcp 65001`，读取端固定按 UTF-8 解"，
结果中文全是乱码（自检抓到：实得 `���Ĳ���`）。**两层原因**：

1. `chcp 65001 >nul &` 这半句本身会干扰 cmd 的输出；
2. 更要紧的 —— **机器的默认控制台代码页不一定是 936**。
   本机实测 `chcp` 报的就是 **65001**（已经是 UTF-8），
   而我却按"中文 Windows 一定是 936"去处理。**假设错了，怎么调都是乱的。**

**修法**：**先问系统当前代码页，再按它解码**。

- 跑一句 `chcp`（cmd）或 `[Console]::OutputEncoding.CodePage`（PowerShell）拿到代码页号；
- 用那个代码页构造 `Encoding` 交给 `StandardOutputEncoding`；
- 结果**按 shell 缓存**（代码页在一次运行期间不会变）；
- 探测失败退到系统 ANSI 代码页。

另外 .NET Core 上必须 `Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)`，
否则 `Encoding.GetEncoding(936)` 会直接抛 —— 框架默认只带 UTF-8/UTF-16 那几个。

## 已知限制

1. **不拦截危险命令**（有意为之，见开头）。
2. **不保存命令历史** —— 本版不做上/下箭头翻历史。
3. **不支持交互式命令**：`-NonInteractive` 意味着等输入的命令（如裸 `python`、
   `diskpart`）会直接失败或超时，而不是给你一个能交互的终端。
   本工具是"跑一条命令看结果"，**不是终端模拟器**。
4. **不解析管道语法**：那条命令整体交给 shell，由 shell 自己解释
   （所以 `|`、`>`、`&&` 都按你选的 shell 的规则走）。
5. **超时后强杀进程树**：如果命令启动了别的东西，那些也会被一起结束。
6. **环境变量/工作目录**：默认用工具箱进程的工作目录，本版没有"选择工作目录"的入口。
7. **输出上限 40 万字符**（防止死循环命令刷爆内存），超出部分会被截断。

## 最小测试脚本

```powershell
# 完整自检（含运行命令八项），预期 71/71
dist\Toolbox.exe --selftest
```

自检里的 8 条用例（**全部只跑只读、无副作用的命令**）：

| 用例 | 判据 |
|---|---|
| shell 解析 | 两种 shell 都解析到**真实存在**的 exe |
| 命令行预览 | 预览里能看到 `/c` `/d` 与 `-NoProfile` `-NonInteractive` |
| cmd 实跑 | `echo` → 退出码 0 且输出含预期内容 |
| PowerShell 实跑 | `Write-Output` → 退出码 0 且输出含预期内容 |
| **中文不乱码** | `echo 中文测试` → 原样取回（这条抓出过一个真 bug） |
| 非 0 退出码 | `exit /b 3` → 如实回报 3，且**不**误判成工具故障 |
| 空命令 | 空串与纯空白都被拒绝，不启动进程 |
| **超时中止** | 3 秒超时生效（实测 3.1 秒返回），并给出中文提示 |

> 自检只跑 `echo` / `exit /b` / `ping 127.0.0.1` 这类命令 ——
> 因为自检是会自动运行的，绝不能在里面执行任何有副作用的命令。
