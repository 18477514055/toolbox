# 批量文件重命名（Toolbox 工具 7）

> 选目录 → 调规则（**边调边看预览**）→ 确认执行 → 可**一键撤销**。

---

## 依赖

| 项 | 说明 |
|---|---|
| 第三方库 | **无** |
| 外部程序 | **无** |
| 复用 | 工具注册/热键/悬浮窗（`IToolboxTool`）、设置存储（`Settings.LastRenameDir`）、目录管理（`AppPaths.Root`）、日志（`Log`）、目录选择对话框（`Microsoft.Win32.OpenFolderDialog`） |

---

## 用法

| 操作 | 说明 |
|---|---|
| **热键** | `Win+Alt+R`（被占用时自动降级到 `Win+Alt+H` / `Ctrl+Alt+R`） |
| 选目录 | 「浏览…」或直接填路径，然后「载入」 |
| 调规则 | 改任何一项，**预览立即重算** |
| 执行 | 点「执行改名」→ 二次确认 → 执行 |
| 撤销 | 点「撤销上次改名」 |

### 规则说明

| 规则 | 行为 | 示例 |
|---|---|---|
| **前缀** | 加在文件名最前面 | `照片.png` → `P_照片.png` |
| **后缀** | 加在**扩展名之前** | `照片.png` → `照片_S.png` |
| **替换** | 查找并替换文件名部分（可不区分大小写） | `IMG_a.jpeg` → `照片_a.jpeg` |
| **序号** | 加在名字前，可设起始 / 位数 / 步长 | `001_照片.png`、`002_...` |
| **时间戳** | 加在名字前，**默认用文件修改时间** | `20240307_照片.png` |
| **扩展名转小写** | `.PNG` → `.png` | — |

规则**叠加顺序**（固定，不随界面填写顺序变）：
`替换 → 时间戳 → 序号 → 前缀 → 后缀 → 扩展名`

例：序号起始 5、位数 2、前缀 `N`、时间戳 `yyyyMMdd`、原名 `a.txt`
→ `N05_20240307_a.txt`

## 安全设计（这是不可逆操作，所以处理得比别的工具更小心）

1. **先预览再执行** —— 「预览」和执行**共用同一个纯函数** `RenamePlanner.Plan`。
   两份各写一份的话，预览里看到的和实际改出来的迟早会不一致，
   而用户是**照着预览点的确定**，那等于骗他。
2. **执行前二次确认**，确认框里写明"将改动 N 个文件"。
3. **重名默认自动加序号**，**绝不覆盖**任何已有文件。
4. **执行后落账本**（`%LOCALAPPDATA%\桌面工具箱\rename-journal.json`），
   支持一键撤销；**账本落盘**，所以重启工具箱后仍能撤销 —— 那正是最需要撤销的时候。
5. **两阶段改名**（先改成临时名，再改成目标名）：
   正序直接改会撞车（把 `a→b`、`b→a` 交换名字时，第一步就失败）。
   先全部改成不冲突的临时名，就与顺序无关了。
6. **只改本目录、不递归子目录** —— 递归改名波及面太大，太容易误伤。
7. 改名失败时**尽量还原成原名**，不把文件卡在 `.tmp` 中间状态。
8. 撤销时**不覆盖任何现有文件**：目标名已被占用就跳过那一条并如实报告。

## 已知限制

1. **不递归子目录**（有意为之，见上）。
2. **只改文件名，不改扩展名内容**（"扩展名转小写"是唯一会动扩展名的规则）。
3. **撤销只保留最近一次操作** —— 刻意如此：能撤两次、三次会让人搞不清当前到底在哪个状态，
   而"撤销"的全部价值就在于**确定性**。
4. **部分撤销失败时账本保留**，可以再点一次撤销重试。
5. **取不到文件修改时间时**（文件被独占占用等）会用当前时间，并在预览的「说明」列里写明。
6. **改名不会移动文件所在目录**（同目录内改名）。
7. 若目标盘是 **FAT/exFAT** 等大小写不敏感的文件系统，"只改大小写"的改名可能不生效
   （系统认为名字没变）——这是文件系统行为，不是本工具的问题。

## 最小测试脚本

```powershell
# 完整自检（含批量改名三项），预期 ≥ 40/40
dist\Toolbox.exe --selftest
```

自检里的三条用例：

| 用例 | 判据 |
|---|---|
| 规则计算 | 7 组规则各自算出的目标名**逐字相符**（含组合规则） |
| 重名 + 非法字符 | 同批次撞名必须自动加序号；含 `\ / : * ? " < > \|` 的名字必须被跳过 |
| 端到端 | **真建文件 → 真改名 → 真撤销还原**；且"目标名已被占用"时自动改名为 `z (1).txt` |

用例覆盖了纯逻辑与真实磁盘两条路径，且**自检结束会删掉自己造的临时目录**。
