# 桌面工具箱 · Toolbox

一个常驻 Windows 托盘的**模块化小工具箱**。12 个功能各自独立开关，按需启用；
点悬浮窗或按热键都能用。

> **零第三方依赖** —— 所有功能都是纯 .NET / Windows 实现，
> 单文件 exe（约 71 MB，运行时已打进包内），拷给别人双击即用。

---

## 功能一览（12 个）

| # | 功能 | 默认键 | 默认开关 | 说明 |
|---|---|---|---|---|
| ① | **快捷剪贴板** | `Win+Shift+V` | ✅ 开 | 历史记录（文本/图片/文件）、搜索、日期筛选、**右键直接复制**、显示文件/图片原位置 |
| ② | **图片裁剪** | `Win+Shift+X` | ✅ 开 | 框选裁剪、改像素尺寸、另存不覆盖 |
| ③ | **格式转换** | `Win+Shift+C` | ✅ 开 | 图片互转（零依赖）+ 文档/PDF（需 LibreOffice 或 Office） |
| ④ | **快捷 AI** | `Win+Shift+A` | ✅ 开 | 读页面 / 选中文本 → 翻译、总结、提问；流式输出 |
| ⑤ | **快捷截图** | `Win+Alt+S` | ✅ 开 | 整屏冻结 → 拖框 → 存 PNG + 复制到剪贴板 |
| ⑥ | **OCR 截图识字** | `Win+Alt+T` | ⬜ 关 | 框选 → 识别文字（中文可用）→ 复制 |
| ⑦ | **批量重命名** | `Win+Alt+R` | ⬜ 关 | 前缀/后缀/替换/序号/时间戳，可预览、可撤销 |
| ⑧ | **哈希校验** | `Win+Alt+H` | ⬜ 关 | MD5/SHA1/SHA256/SHA512、两文件对比、期望值比对 |
| ⑨ | **二维码工具** | `Win+Alt+Q` | ⬜ 关 | 生成 + 扫描（编解码全部自实现） |
| ⑩ | **窗口置顶** | `Win+Alt+P` | ⬜ 关 | 当前窗口置顶 / 取消（toggle） |
| ⑪ | **运行命令** | `Win+Alt+X` | ⬜ 关 | 交给 cmd 或 PowerShell 执行，输出回显 |
| ⑫ | **批量打包** | `Win+Alt+G` | ⬜ 关 | 打包成 zip（零依赖）或 rar（需 WinRAR） |

> **默认只开常用的 5 个**（①~⑤）。其余 7 个在「设置 → 功能开关」里一键打开。
> 热键被别的程序占用时会**自动降级**到备选键，并明确告诉你换成了什么。

## 快速开始

1. 下载 `dist/Toolbox.exe`（或 Releases 里的压缩包）
2. 双击运行 —— 右下角出现托盘图标，屏幕右侧出现竖排小悬浮窗
3. 点悬浮窗图标就能用；或者按热键

**不需要安装任何东西**：.NET 运行时已打进 exe。

**退出**：右键托盘图标 → 退出。

---

## 功能开关（总开关 + 单个开关）

托盘图标右键 → **设置 → 功能开关**：

- **总开关**：一键让整个工具箱安静下来（所有功能停止运行，程序还在）
- **每个功能一个开关**：决定它**是否运行**、以及**是否显示在悬浮窗上**
- 三个批量按钮：全部开启 / 全部关闭 / 恢复默认
- 改完**点保存立即生效**，不用重启

关掉的功能不只是"藏起来"——它**真的会停止**（不注册热键、不监听剪贴板）。

## 热键可以一个都不设

**所有热键都是可选的**。设置里有「清空全部热键」按钮 ——
清空后工具箱不占用任何快捷键，全靠点悬浮窗/托盘，体验一样顺。

## 数据在哪

```
%LOCALAPPDATA%\桌面工具箱\
├─ Toolbox.exe        程序
├─ settings.json      你的设置
├─ clipboard\         剪贴板历史
├─ logs\              日志
└─ screenshots\       截图默认保存位置
```

**便携模式**：exe 旁边放一个空文件 `portable.txt`，数据就会存在 exe 同级的 `data\` 里，
**删掉文件夹即彻底卸载**。

## 依赖说明（诚实的边界）

| 功能 | 依赖 |
|---|---|
| 剪贴板 / 裁剪 / 图片转换 / 截图 / OCR / 重命名 / 哈希 / 二维码 / 置顶 | **零依赖** |
| AI | 本地 Ollama（需装）**或**任意 OpenAI 兼容 API（零安装，填地址+Key） |
| 文档 / PDF 转换 | LibreOffice **或** Microsoft Office（不装则该格子不可用，不影响其它） |
| RAR 打包 | **需要装 WinRAR** —— RAR 是专有格式，其压缩算法受许可保护，任何人都不能合法地把"创建 RAR"打进自己的软件分发 |

## 从源码构建

需要 **.NET 9 SDK**（Windows）。

```powershell
# 构建
dotnet build src\Toolbox\Toolbox.csproj -c Release

# 发布单文件
dotnet publish src\Toolbox\Toolbox.csproj -c Release -o dist

# 自检（80 项左右，含真实功能的端到端验证）
dist\Toolbox.exe --selftest
```

⚠️ 本机若缺 `APPDATA` / `ProgramFiles(x86)` 环境变量，`dotnet` 会报
`Value cannot be null (Parameter 'path1')` —— 补上即可（`run-toolbox.cmd` 已内置）。

## 项目结构

```
src\Toolbox\
├─ Core\          基础设施（日志 / 路径 / P/Invoke / 剪贴板读写 / DPI 换算）
├─ Shell\         外壳（托盘 / 悬浮窗 / 热键 / 设置 / 工具注册表 / 功能开关）
├─ Tools\         12 个功能，一个功能一个目录
│  ├─ Clipboard\     快捷剪贴板
│  ├─ ImageCrop\     图片裁剪
│  ├─ Convert\       格式转换
│  ├─ Ai\            快捷 AI
│  ├─ Screenshot\    快捷截图
│  ├─ Ocr\           OCR 截图识字
│  ├─ BatchRename\   批量重命名
│  ├─ HashCheck\     哈希校验
│  ├─ QrCode\        二维码工具
│  ├─ WindowTopmost\ 窗口置顶
│  ├─ CommandRunner\ 运行命令
│  └─ Archiver\      批量打包
└─ SelfTest.cs    自检（80+ 项，含端到端验证）
```

**每个功能目录下都有自己的 `README.md`**，写明依赖、用法、**已知限制**和测试要点。

## 加一个新功能要动哪些地方

1. 在 `Tools\` 下新建目录，实现 `IToolboxTool` 接口
2. 在 `Shell\ToolGate.cs` 的默认策略里登记（决定默认开还是关）
3. 在 `App.xaml.cs` 的注册区加一行 `_registry.Add(new XxxTool());`
4. 如需热键降级链，在 `HotKeyFallbacks` 里加一条

> ⚠️ **第 3 步最容易漏**（代码写好但没接线，编译不报错）。
> 自检里的「工具发现」用例会**读源码核对**，漏了会立刻变红。
